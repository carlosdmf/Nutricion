# Nutricion

Proyecto de ejemplo con backend y frontend para una aplicación de nutrición.

Estructura:
- `backend/` – servidor Node.js
- `frontend/` – aplicación React con Vite

Instrucciones rápidas:
1. Instalar dependencias: `npm install` en `backend` y `frontend`.
2. Ejecutar backend: `node server.js` (o `npm run dev` si está configurado).
3. Ejecutar frontend: `npm run dev` en `frontend`.
